# Brand Icons

Thư mục này chứa icon kênh giao tiếp dùng lại nhiều nơi trong UI.

- `ai.svg`: icon cho thao tác AI.
- `logo_Zalo.webp`: logo Zalo dùng cho nút nhắn Zalo.
- `logo_Gmail.webp`: logo Gmail dùng cho nút gửi email.

Giữ nguyên tên file để component `BrandIcon` tự nhận ảnh mới mà không cần sửa code.
Nên dùng ảnh nền trong suốt nếu có, kích thước gợi ý từ 64x64 trở lên.
